#  Basic CV-generator.

👉 Overview

A basic HTML and CSS based CV Generator web app that helps users easily create and preview their professional resumes. The user fills out a form with personal, educational, and experience details, which are then displayed in a styled CV template. It's designed to be lightweight, responsive, and beginner-friendly—ideal for quick resume generation without complex setups.

👉 Technologies Used

 • HTML5

 • CSS3
